# Java-Multithreading-Practise
A Java learning project focused on understanding multithreading, concurrency, and thread safety.

## About the Project
This project simulates a ticket booking system where hundreds of users try to buy a limited number of tickets (e.g., 100 tickets) at the exact same time. 

The goal is to demonstrate:
* How to create and run multiple threads in Java.
* What happens when multiple threads access shared data without protection (race conditions).
* How to make the code thread-safe so that tickets are never oversold.

## Technologies Used
